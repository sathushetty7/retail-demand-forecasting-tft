# Retail Demand Forecasting using TFT

An end-to-end deep learning project for forecasting retail product demand using the Temporal Fusion Transformer (TFT).

## Dataset

M5 Forecasting dataset (Walmart) https://www.kaggle.com/competitions/m5-forecasting-accuracy/data.
